# Multi-Sensor Smart Home Safety & Automation System

## Overview
This project implements a smart home safety and automation system using multiple sensors integrated with Arduino. The system detects fire, motion, temperature variation, and proximity, and automatically triggers actuators such as servo motors, fans, buzzers, and lights.

## Sensors Used
- Ultrasonic Sensor (Distance Detection)
- Smoke Sensor (Fire Detection)
- Temperature Sensor (Overheat Monitoring)
- PIR Sensor (Motion Detection)

## Actuators Used
- Servo Motor (Door Control)
- DC Fan (Ventilation Control)
- Buzzer (Alarm System)
- LED (Lighting Automation)

## Functional Logic
- Fire detected → Buzzer ON + Fan ON
- Motion detected → Light ON
- Object detected near door → Servo rotates
- High temperature → Fan ON

## Applications
- Smart Home Automation
- Fire Safety Systems
- Intrusion Detection
- Energy Efficient Automation
